# 自建 Gazebo World 设计

## 1. 坐标系与外边界

- 世界原点：场地中心 `(0, 0)`
- 场地内部尺寸：`12 m × 8 m`
- x 轴范围：`-6 m ～ 6 m`
- y 轴范围：`-4 m ～ 4 m`
- 墙体高度：`1.0 m`
- 墙体厚度：`0.2 m`
- TurtleBot3 初始位置：`(-4.0, -2.5, 0)`

## 2. 外墙中心与尺寸

| 外墙 | 中心 `(x, y, z)` | 尺寸 `(长, 宽, 高)` |
|---|---|---|
| 北墙 | `(0, 4, 0.5)` | `(12.2, 0.2, 1.0)` |
| 南墙 | `(0, -4, 0.5)` | `(12.2, 0.2, 1.0)` |
| 东墙 | `(6, 0, 0.5)` | `(0.2, 8.0, 1.0)` |
| 西墙 | `(-6, 0, 0.5)` | `(0.2, 8.0, 1.0)` |

外墙在四个角略微重叠，避免机器人从墙角缝隙离开世界。

## 3. 房间分区与中央通道

使用 `x=0` 的纵向隔墙，将场地分成西区和东区两个独立区域。

隔墙中间保留 `2.4 m` 宽的门：

- 门的 y 轴范围：`-1.2 m ～ 1.2 m`
- 西区：`x < 0`
- 东区：`x > 0`

| 隔墙 | 中心 `(x, y, z)` | 尺寸 `(长, 宽, 高)` |
|---|---|---|
| 北侧隔墙 | `(0, 2.6, 0.5)` | `(0.2, 2.8, 1.0)` |
| 南侧隔墙 | `(0, -2.6, 0.5)` | `(0.2, 2.8, 1.0)` |

`2.4 m` 的门宽能够给 TurtleBot3 Burger 和 Nav2 costmap 留出充足的通行及转向空间。

## 4. 障碍物设计

障碍物分散在不同区域，不占用中央门，也不阻挡 TurtleBot3 出生点。

| 障碍物 | 形状 | 中心 `(x, y, z)` | 尺寸 |
|---|---|---|---|
| 西北障碍物 | 立方体 | `(-3.2, 2.2, 0.3)` | `0.6 × 0.6 × 0.6 m` |
| 东北障碍物 | 长方体 | `(3.1, 2.2, 0.4)` | `1.2 × 0.7 × 0.8 m` |
| 东南障碍物 | 圆柱体 | `(3.2, -2.2, 0.35)` | 半径 `0.45 m`，高度 `0.7 m` |

设计理由：

- 三个障碍物具有不同尺寸，满足考核要求。
- 圆柱体与箱体具有不同的 LaserScan 轮廓，便于检查建图质量。
- 西南区域留给 TurtleBot3 出生和初始移动。
- 中央门前后不放障碍物，避免形成过窄通道。

## 5. 俯视草图

```text
y=4    ┌───────────────────────┬───────────────────────┐
       │                       │                       │
       │   ■ 西北立方体        │       ▬ 东北长方体    │
       │   (-3.2, 2.2)         │       (3.1, 2.2)      │
y=1.2  │                       │                       │
       │                                               │
       │              2.4 m 中央通道                   │
       │                                               │
y=-1.2 │                       │                       │
       │   ● Burger 出生点     │       ○ 东南圆柱体    │
       │   (-4.0, -2.5)        │       (3.2, -2.2)     │
       │                       │                       │
y=-4   └───────────────────────┴───────────────────────┘
      x=-6                    x=0                     x=6
```

图例：

- `■`：立方体
- `▬`：长方体
- `○`：圆柱体
- `●`：TurtleBot3 Burger 出生点
- 中间上下两段竖线：房间隔墙
- 中央空白：宽 `2.4 m` 的连通门
