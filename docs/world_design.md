# 自建 Gazebo World 设计说明

## 目标

在不过度制造狭窄通道的前提下，提供足够清晰的房间结构和障碍物特征，供
TurtleBot3 Burger 的 LaserScan、SLAM Toolbox 和 Nav2 后续复用。

## 坐标设计

- 世界边界：`x=-6…6 m`，`y=-4…4 m`
- 西区：`x<0`
- 东区：`x>0`
- 中间隔墙：`x=0`，上下各 `2.8 m`
- 中央连通门：`y=-1.2…1.2 m`，净宽 `2.4 m`
- 出生点：`(-4.0, -2.5, 0)`

外墙厚 `0.15 m`、高 `1.0 m`。所有墙和障碍物都是 static model，同时具备
collision 和 visual geometry。中央门宽明显大于 Burger 本体和预期
costmap 膨胀范围，便于先完成核心导航任务。

## 障碍物

1. 西北区：`0.6 × 0.6 × 0.6 m` 小立方体。
2. 东北区：`1.2 × 0.7 × 0.8 m` 旋转长方体。
3. 东南区：半径 `0.45 m`、高 `0.7 m` 圆柱体。

三者分散在不同位置，不封堵中央门，也不遮挡出生点。不同轮廓可以帮助判断
建图结果是否出现重影、丢边或过度膨胀。

## 现场验证重点

- Burger 是否落地稳定、无持续滑动或弹跳。
- 外墙 collision 是否能阻止机器人离开。
- 中央门和每个障碍物周围是否能用 teleop 顺利通过。
- Gazebo 俯视与 RViz LaserScan 是否对应。
- `/scan` 对三个障碍物的轮廓是否有有效回波。

若现场发现门口转弯空间不足，优先调整障碍物位置，不缩小机器人 footprint 或
关闭安全膨胀。
